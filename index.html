Download the Installer

Windows will show a security warning when you run this file — that is normal.

When the blue screen appears, click More info, then click Run anyway.

How to Install a Skill

1
Click Download install.bat above and save the file anywhere on your computer.
2
Double-click the downloaded file to open it.
3
If a blue Windows warning screen appears, click More info, then Run anyway.
4
A menu will appear. Type the number of the skill you want and press Enter. Type A to install all, or Q to quit.
5
Open Claude Code and start a new chat. Your skill is ready to use.
